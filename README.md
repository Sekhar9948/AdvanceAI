# EdvanceAI Education Tool

A modern, responsive AI education tool featuring a sleek UI built with CustomTkinter and PyQt6. This application provides an immersive learning experience for various AI models.

## Features

- **Dynamic UI**: Combines CustomTkinter and PyQt6 for maximum flexibility and aesthetics
- **Theme Switching**: Elegant dark/light mode toggle
- **Responsive Design**: Optimized for various screen sizes, including Raspberry Pi compatibility
- **Model Categories**:
  - Vision Models (Hand Gesture Detection, Object Classification, Pose Detection)
  - Speech Models (Speaker Identification, 3D Voice Command)
  - Text-Based Models (Handwriting Digit Recognition, N-gram, Spam Detection, Language Classification)
  - Emotion Models (Emotion Detection)
- **Smooth Animations**: Fluid transitions between screens and components
- **Expandable Architecture**: Designed for easy integration of new AI models

## Installation

1. Clone this repository
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the application:
   ```
   python main.py
   ```

## System Requirements

- Python 3.8+
- Raspberry Pi 4 or newer (for Pi deployment)
- 4GB RAM recommended
- Display with 800x600 resolution or higher
